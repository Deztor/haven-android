# Android APK «Haven»

Тонка Capacitor-оболонка: застосунок відкриває опублікований Haven https://warden-web.lovable.app,
тому кожна зміна сайту (злиття в Deztor/warden-web) видна в APK після перезапуску без перевстановлення.
Новий APK потрібен лише коли змінюється цей репозиторій.

Код сайту живе в приватному Deztor/warden-web; тут лише оболонка (адреса сайту, іконка, налаштування Android),
без секретів, тому репозиторій публічний: так APK завантажується з телефона без входу в GitHub, а Haven
може перевіряти нову версію.

- Збірка: `.github/workflows/apk.yml` на хмарному ранері GitHub. На PR лише перевіряє, що APK збирається;
  на `main` (або вручну, Actions → Android APK → Run workflow) підписує й публікує реліз `apk-vN`.
  Зміни лише в `*.md` нову версію не збирають.
- Остання версія завжди тут: https://github.com/Deztor/haven-android/releases/latest/download/haven.apk
- Підпис: секрети репозиторію `ANDROID_KEYSTORE_BASE64` (PKCS12, alias `haven`) і `ANDROID_KEYSTORE_PASSWORD`.
  Без них APK збирається, але не публікується. Той самий ключ потрібен для кожного оновлення: новий ключ =
  видалити застосунок і встановити заново.
- Версія: `versionCode` = номер запуску workflow; Haven бачить її в user agent як `HavenApk/N` і в налаштуваннях
  профілю пропонує «Оновити застосунок», коли на GitHub є новіший `apk-vN`.
- Нові вікна (`window.open`, `target="_blank"`) і переходи: сторінки Haven відкриваються в застосунку, решта — у
  браузері телефону (`MainActivity.java`). «Свої» — лише https, точний хост, порт 443, без user info.
- Камера й мікрофон сторінці не надаються.
- Без інтернету показується `www/offline.html`. На старому WebView без `DOCUMENT_START_SCRIPT`/`WEB_MESSAGE_LISTENER`
  Haven не відкривається, натомість `www/index.html` просить оновити Android System WebView.

Встановлення на телефоні: відкрити посилання вище в Chrome → завантажити → дозволити Chrome встановлювати
застосунки → «Встановити». Наступні версії ставляться поверх, вхід і дані лишаються.

Відомі обмеження: завантаження файлів, створених на сторінці (експорт JSON/CSV в адмінці), у застосунку не працюють.
